# 风格参考库使用规则

## 定位

A-F 文件是问题检索库，不是六个必须选择的风格维度。先完成剧本分析，再由 N2 基于该分析形成临时导演命题，然后才按临时命题暴露的具体视听问题检索。风格图书馆只校准方法，不能凭空产生导演命题。

## 路由

| 文件 | 仅在需要解决以下问题时检索 |
|---|---|
| `A-情绪基调.md` | 情感温度、克制或外放、幽默与悲剧的表达距离 |
| `B-类型机制.md` | 悬疑、恐怖、犯罪、科幻等类型的信息和期待管理 |
| `C-动作与对抗.md` | 动作可读性、身体对抗、战争或灾难的空间关系 |
| `D-人物关系.md` | 爱情、家庭、成长等人物关系的视听表达 |
| `E-叙事形式.md` | 伪纪录、公路、歌舞、动画或实验形式的特殊规则 |
| `F-社会视角.md` | 现实、历史、政治和社会语境中的摄影机立场 |

通常只检索一个文件中的一个相关小节。确有复合问题时最多检索两个小节，不以“覆盖完整”为目标。

## 检索方式

先用标题搜索定位，不要默认加载整份文件。例如：

```bash
rg -n '^## |^### ' 'references/style-library/B-类型机制.md'
```

随后只读取相关段落。

## 四项引用检查

每次借鉴都回答：

1. 当前剧本问题是什么？
2. 借鉴的是哪项具体方法，而非哪种表面风格？
3. 它是否符合已经确认的摄影机立场？
4. 改写成什么项目规则，适用于哪里？

任何一项无法回答，就不要引用。

## 禁止方式

- 不按类型数量分配导演数量。
- 不用导演姓名代替镜头、声音、表演或剪辑规则。
- 不把冷暖、滤镜、画幅等表层差异当成导演命题。
- 不同时采用互相冲突的方法，再用“融合”掩盖矛盾。
- 不追求复刻某位在世导演的整体个人风格；只讨论可泛化的电影语言方法和具体作品中的技术选择。
- 用户要求“完全像某导演”时，明确拒绝把相似度作为验收标准，转而提取可泛化的摄影、剪辑、表演或声音特征；用户指定多个导演时先列冲突，再只保留一套主导语法和有限的段落变量。
- 任何具名参考都必须记录 `reference_source`、提取的方法、适用场景和停止使用条件；未记录来源范围时不得写入视听宪法。

## 合格写法

不合格：

> 爱情部分采用王家卫风格，科幻部分采用维伦纽瓦风格。

合格：

> 全片保持克制的观察距离。人物关系变化主要通过双人构图中的距离和遮挡表达；科幻设定通过人物日常行动逐步显露，不用解释性对白集中介绍。两项方法服从同一摄影机立场。
