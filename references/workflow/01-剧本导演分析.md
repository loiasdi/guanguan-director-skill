# 第一步：剧本导演分析

## 节点契约

- 节点：`N1`
- 输入：原始剧本/梗概、项目约束
- 循环单元：场景或事件序列
- 输出：通过证据检查的剧本导演分析、导演问题清单、待确认假设
- 出边：`G1 通过 → N2`；`G1 修改 → N1 当前分析单元`

## 目的

把剧本转化为导演决策所需的证据，不在这一阶段选择导演、滤镜或镜头风格。

## 分析顺序

### 1. 建立事件骨架

逐场或逐事件单元标注：

- 场景开始状态
- 核心可见行动
- 阻力或对抗
- 场景结束状态
- 发生的价值转变
- 若删除此场，全片会缺少什么

无法改变状态、提供信息、发展关系、制造节奏或建立主题动作的内容，标记为待删减或待合并，不直接删除。

### 2. 判断故事主体

用一句话分别回答：

- 这是谁的故事？
- 他/她持续在做什么？
- 什么力量阻止这件事？
- 故事最终要求观众重新理解什么？

当存在群像、多线或视角欺骗时，分别写出表层主体与实际主体。

### 3. 拆解类型功能

不要只列类型名称。为每个类型成分指定功能：

| 功能 | 含义 |
|---|---|
| 故事主体 | 主要戏剧关系和观众持续关心的问题 |
| 世界规则 | 故事成立所依赖的时代、科技、超自然或制度设定 |
| 冲突机制 | 推动人物采取行动的对抗方式 |
| 信息机制 | 悬念、误导、调查、倒叙等信息释放方式 |
| 情绪基调 | 观众体验故事时的主要情感温度 |
| 社会语境 | 故事与现实、历史、阶层或制度的关系 |

一个成分可以承担多个功能，但必须确定主次。例如“科幻爱情悬疑”可能是爱情作为故事主体、科幻作为世界规则、悬疑作为信息机制。

### 4. 分析人物关系与表演任务

针对核心人物记录：

- 对外目标与可见行动
- 习惯性的自我保护方式
- 与他人的空间关系如何变化
- 哪些事实通过语言表达，哪些应通过行为表达
- 关键表演转折发生在哪个动作、停顿或选择上

不要写无法被表演或拍摄的心理判断。把“他感到被背叛”转换为剧本证据，例如“他停止收拾行李，把钥匙放回桌面”。

### 5. 建立信息地图

对关键秘密、规则和转折标注：

- 角色知道什么
- 观众知道什么
- 何时释放
- 通过画面、声音、对白还是剪辑关系释放
- 提前释放或延后释放会产生什么效果

识别观众信息量相对角色是大于、等于还是小于，并标出变化节点。

### 6. 提取视听资源

只从剧本中提取已有或可合理发展的材料：

- 核心空间及其权力关系
- 反复出现的动作
- 有叙事分量的物件
- 环境声、机械声、呼吸、沉默或画外声
- 时间、天气、光源和材质
- 可形成视觉母题的重复与变化

不要因为某个意象“好看”就加入。每个候选意象都必须说明它与人物行动或主题变化的关系。

### 7. 标记风险与约束

检查：

- 不可拍的心理叙述
- 主要依靠对白解释的段落
- 类型功能彼此冲突的位置
- 情绪连续同强度的位置
- 空间重复但缺乏变化的位置
- 高成本或执行不确定的场面
- 用户给出的时长、预算、演员、场地和媒介约束

未知约束标注为待确认，不自行假设大制作或零成本。

### 8. 提出导演问题

把分析收束为 3-7 个必须由导演方案回答的问题，例如：

- 摄影机应当亲近角色，还是保持审视距离？
- 观众应比角色更早还是更晚发现真相？
- 最重的情感通过脸、身体、空间还是声音表达？
- 世界设定应当被解释，还是让观众从日常行动中发现？

这些问题是第二步生成导演命题的输入。

## 输出格式

```markdown
# 剧本导演分析｜项目名

## 一句话导演理解
[不是剧情梗概，而是对这部作品如何成立的判断]

## 故事骨架与价值变化
[按场景或序列概括]

## 类型功能与主次
| 成分 | 功能 | 主次 | 剧本证据 |

## 人物关系与表演任务
[核心人物及关键变化]

## 信息地图
| 信息 | 角色何时知道 | 观众何时知道 | 当前载体 | 导演影响 |

## 视听资源
[空间、动作、物件、声音、时间、候选意象]

## 风险与约束
[问题、证据、影响]

## 第二步必须回答的导演问题
1. ...
```

## 自检清单

- 每个重要判断是否有剧本证据？
- 是否区分了故事主体、世界规则、信息机制和情绪基调？
- 是否把多类型误写成多风格？
- 是否把心理判断转换为可见或可听的依据？
- 是否识别了观众与角色的信息差？
- 候选意象是否来自故事，而非装饰性添加？
- 导演问题是否具体到后续可以制定规则？
