# 第五步 B：镜头组内镜头序列规则

## 规则契约

- 使用节点：`N5.3`
- 输入：G5A 已确认的单个镜头组、上一组结尾、下一组叙事入口和相关宪法规则
- 处理单位：一个镜头组的完整有序镜头序列
- 输出：内部镜头序列记录，交给 N5.4 格式化
- 不负责：重新划分节拍或镜头组、分配全局镜号、九列格式化、用户闸门和文件编排

单个镜头不是工作流循环单元。必须一次生成当前镜头组的完整序列，再以整组为单位检查和修订。

## 目录

- 必须执行的生成顺序
- 镜头完成后的时长估算
- 内部序列记录
- 整组通过条件
- 可选参考调用

## 必须执行的生成顺序

### 1. 建立序列骨架

按镜头组中的节拍顺序写出：

```text
组入口
→ 必须被观众读取的行动/信息/反应
→ 节拍之间的因果、递进、并列或对比关系
→ 组内价值变化
→ 组出口及下一组入口
```

先确定内容顺序，不先选择景别、角度或特殊手法。

### 2. 判断连续呈现还是切镜

先检查整组是否能在一个连续镜头内完成。只有出现以下必要切点时才新增镜头：

- 信息焦点发生变化
- 动作与反应需要分离
- 空间关系需要重新建立
- 时间发生省略或跳跃
- 视听宪法允许在当前叙事重心进行强调
- 声画关系需要从一个载体转移到另一个载体

不得按句号、台词行数、节拍数量或预计镜数机械切镜。每一个切点都必须能说明“不切会损失什么”。

### 3. 一次生成完整镜头序列

完成全部切点后，再一次性为组内所有镜头确定：

- 可见行动与可听内容
- 景别、角度、构图和必要的镜头运动
- 组内前后镜头的入口与出口
- 与上一镜头组结尾、下一镜头组入口的连接
- 剧本、节拍、宪法和节奏溯源

此时暂不填写任何秒数。局部镜头设计必须服从整组的主要叙事目的。不能为了一个漂亮镜头破坏组内因果或全片宪法。

#### 3A. 强制建立镜头内部视觉时间线

visible_action 只能作为镜头摘要，不能作为完整画面设计。每个镜头必须在时长计算前写出 visual_timeline，按发生顺序记录：

镜头进入状态 → 主要动作开始 → 台词/动作期间的可见变化 → 人物、物件或空间反应 → 镜头退出状态

每个阶段至少包含 phase_id、visible_action、change_type、relation、source；有对白时填写 dialogue_segment。change_type 只能是 entry、action、focus、light、reaction、space、result、exit 之一；relation 只能是 sequential 或 concurrent。阶段必须覆盖剧本中的关键可见动作、反应、物件变化、焦点/构图变化与退出条件，不得只写“看着”“沉默”或“缓慢推近”。这不要求增加剪切；一个镜头可以通过连续调度完成多个阶段。

`visible_action` 只记录无声观看画面也能辨认的动作与变化。角色说话时，可以写“她开口”“他转向对方”“嘴唇停住”等可见表演，但不得写出、复述或概括台词文字；台词原文只进入 `dialogue_segment`、`spoken_segments.text` 和公开表的声音栏。画面中真实出现的字幕、屏幕文字、信件或标牌原文不属于台词，可保留在 `visible_action`，但必须注明可见载体。

每个 phase 必须描述相对于上一 phase 新发生的可见事实。禁止把同一句动作复制多次，再分别追加“形成镜头进入状态”“主要动作或信息被观众读取”“动作结果稳定并提供下一镜入口”等流程术语；这些不是摄影机可见内容，也不能构成阶段变化。若镜头只有一个实际可见事件，就只记录真实事件和它造成的可见结果，不得伪造三个阶段。需要更丰满的画面时，必须回到剧本动作、人物反应、物件状态、焦点、空间关系或光线变化中设计真实进程。

中间发生的动作、光线、焦点、声音或台词转折不得因为没有剪切而合并成一句摘要。如果台词中间存在剧本明确的视觉事件，必须拆成独立 phase_id，并保留原文顺序。


### 4. 镜头完成后逐镜估时

只有整组镜头的画面、声音、切点和顺序全部确定后，才进入一次整组内的计时遍历。计时不是独立工作流循环，也不能回头用 N3 或 05A 的篇幅权重填满秒数。

#### 4.1 固定计时输入

逐镜保留剧本中的完整台词、旁白和声音顺序，不得为了计时合并、调换或概括原文。先把镜头拆成：

生成前读取当前组的 `required_content_ids` 和对应完整原文。每个 ID 必须写入一个或多个镜头的 `source_content_ids`；对白、旁白、画外音、广播和字幕必须逐字写入 `spoken_segments.text` 或对应声音字段。跨镜拆分只能落在自然语义边界，按镜号拼接后必须与原文一致。“同事OS”“对白”“赵敏对白”“系统广播”等类别摘要不构成覆盖。含语言内容的组不得通过把镜头标成 `timing_mode: action` 并令 `spoken_segments: []` 来绕过声音计时。

```text
台词前事件
→ 台词/旁白期间的声音、动作和摄影机运动
→ 台词后事件
```

没有台词时，按实际发生顺序列出动作、视觉变化、声音节点和观众读取目标。每个事件标注为“先后”或“同时”；未列出的情绪、停顿或氛围不得转化为秒数。

visual_timeline 是画面设计的主数据；pre_dialogue_events/concurrent_events/post_dialogue_events 只用于计时校验，不能替代它。它们必须与时间线同源、同顺序；中间发生的事件不得只出现在计时字段里。


#### 4.2 台词或旁白主导镜头

只能使用两种计时方法：

1. `measured_audio`：存在可定位的演员朗读、用户音频、TTS 文件或计时工具输出。必须记录 `timing_evidence` 的文件/工具、片段起止与测量秒数；Agent 自称“实读”或“在脑中演一遍”不算测量证据。
2. `deterministic_fallback`：没有测量证据时强制使用固定算法，不得根据“克制、沉重、情绪重、重点场景”等描述自行选择慢语速。

中文对白/旁白的固定算法：

```text
有效中文字符数 = 去掉标点和空格后的汉字、数字及需要读出的字母数
基础朗读时间 = 有效中文字符数 ÷ 5.0 字/秒
台词时间 = 基础朗读时间
         + 每处“……”或“...”明确迟疑 0.8 秒
         + 剧本明确标注的定量停顿
         + 同一镜头内每次说话人切换 0.3 秒
```

逗号、句号、问号和感叹号的正常语气已包含在 5.0 字/秒中，不再逐项加时。语速只能使用以下三档：普通说话使用 5.0 字/秒；同一句台词旁有“抢着说/快速说/抢话/打断”等直接表演指令时使用 6.0 字/秒；有“缓慢说/一字一顿”等直接表演指令时使用 3.0 字/秒。非默认语速必须在 `rate_source` 引用该表演指令原文；场景节奏、情绪判断和导演形容词不能改变语速。非中文台词没有测量证据时使用 150 词/分钟，并采用相同的明确停顿规则。

每个 `spoken_segment` 必须记录原文、有效字符/词数、方法、语速、停顿明细和小计。缺任一项不得写 `duration_seconds`。

计时回归例：

```text
台词：你有没有想过……离开？
有效字符：8
基础时间：8 ÷ 5.0 = 1.6秒
一处省略号：+0.8秒
转身、前倾、缓慢靠近：与台词并发，不另加
未写出台词前等待或台词后反应：+0秒
镜头时间：max(2.4, 1.0) = 2.4秒 → 2秒
```

若要写成 10 秒，必须另外列出合计约 7 秒、具有 `event_source`、可见/可听变化和退出条件的顺序事件；仅凭“关系谈判”“克制表演”或“缓慢推近”不得加时。

旁白跨越多个镜头时，先取得整段朗读总时长，再按语义短句建立声音段并分配到镜头。一个声音段可以跨镜形成声音桥；不得让每个镜头重复承担整段旁白时长。

#### 4.3 额外画面与并发规则

额外画面必须是可见动作、可见变化、声音节点或明确反应，不能只写“留白”“氛围”或“情绪需要”。台词镜头中的动作和摄影机运动默认与台词并发；只有剧本顺序或明确的镜头设计把事件放在台词前后时才允许相加，并记录 `event_source`。按以下方式计算：

```text
镜头时长
= 台词前顺序事件之和
 + max(台词朗读时间, 台词中同步动作, 同步摄影机运动, 同步视觉读取)
 + 台词后顺序事件之和
```

多个阶段依次发生时，分别计算后再相加；同一阶段同时发生的项目只取耗时最长者。人物边说边转身、摄影机同时跟随时，动作和运动包含在台词时间内，不能重复相加。摄影机的“缓慢推近”“固定观察”本身不产生额外秒数；只有其完成是明确退出条件时才进入并发项。没有独立可见变化的凝视、呼吸或沉默，自动估算最多 1.0 秒；超过 1.0 秒必须拆成具备可观察变化与退出条件的事件，否则按 0 秒处理。

#### 4.4 无台词镜头

- **动作镜头**：按动作开始、过程、结果的真实顺序估时；先后事件相加，同时事件取最长值。
- **有内部变化的空镜**：按灯光、天气、物件、声音或摄影机揭示的实际时间线估时。
- **静态空镜**：必须填写 `viewer_reads` 和 `exit_condition`，说明观众要读取什么、何时已经读完。单一物件或单一环境信息通常从 2-3 秒起估；建立空间关系通常从 3-5 秒起估；多个信息需要扫描时通常从 4-7 秒起估。这些范围只是在缺少可测动作时的读取基线，不是按景别套用的模板。

静态空镜若没有读取目标、退出条件、声音节点或内部变化，删除该镜头或使用能让单一信息被看清的最短时间；不得用它填补目标片长。

#### 4.5 汇总与异常处理

每镜完成计时后再自下而上求和：

```text
单镜自然时长之和 → 镜头组自然时长 → 场景自然时长 → 全片自然时长
```

内部保留小数计算值，写入 `duration_seconds` 前取最接近的整秒，最低 1 秒，并检查舍入后的累计误差。`duration_basis` 必须写成能复算的算式，例如 `0.6 + max(1.5, 1.2) + 1.0 = 3.1 → 3秒`；“对白、动作与焦点转移”“关系需要”“慢节奏”不是算式。超过 10 秒的镜头必须记录逐段内部事件时间线；超过 15 秒还必须说明持续观看的叙事意图和至少一项可观察的内部变化。没有这些依据时缩短或重新设计。

目标片长只在自然时长汇总后比较。超出硬约束时，通过删减内容、调整表演、合并/拆分镜头或回退上游解决；短于目标时不得拉长现有镜头填满，必须接受自然时长或新增有叙事依据的内容。

## 整组通过条件

当前镜头组序列必须同时满足：

- 覆盖该组所有必要节拍，没有漏拍的行动、对白、声音或反应。
- `required_content_ids` 全部出现在镜头的 `source_content_ids` 中；所有语言内容按镜号拼接后与完整执行稿逐字一致，没有被类别摘要替代。
- 没有找不到节拍或剧本来源的孤立镜头。
- 每镜都有按发生顺序排列的 visual_timeline 和 visual_coverage；时长达到 8 秒时至少有 2 个阶段且至少 2 种 change_type，达到 12 秒时必须有过程、反应、焦点、空间关系或动作结果的可观察变化。
- 相邻 phase 的 visible_action 不能相同或只替换流程性尾句；所有 phase 去掉流程术语后仍必须代表不同的可见事实。
- visual_timeline 中的每个关键可见阶段都必须在九列的“画面内容”中以自然语言语义出现；只出现在计时事件中不算覆盖，也不得把内部阶段标签原样输出。
- 每次切镜都有叙事、信息、空间、时间或宪法理由。
- 镜头顺序能读出该组的因果或关系变化。
- 组入口承接上一组，组出口为下一组提供明确入口。
- 序列声明 `timing_schema: shot-timing-v2`，且不存在 `duration_budget_seconds` 或其他组/场景秒数预算字段。
- 每镜先完成内容设计再估时；台词、动作、并发关系、空镜读取目标和退出条件均可追溯。
- `measured_audio` 有外部证据；否则严格使用确定性算法。每个 `duration_basis` 都是可复算算式，不是文字理由。
- 组总时长由单镜自然时长求和，没有为了贴合上游预算而拉长或压缩。
- 超过 10/15 秒的镜头分别具备内部时间线与长时观看依据。
- 景别、角度、运动、声音和表演符合视听宪法。
- 制作条件允许执行；无法执行的设计已有降级方案。

若只存在局部问题，修订整组序列中的相关位置后重新运行全部检查。最多三轮仍不成立时，使用最清晰的标准镜头组合完成该组并登记取舍；若根因是组边界错误，交回 G5A。

## 可选设计参考

先执行前面的强制生成顺序。只有当前组存在多种合理组织方式时，才从本节选择候选方法；不要为了使用参考而增加镜头。参考方法不能覆盖 05A 已确认的组目的、节拍范围、05B 自下而上的计时结果或视听宪法。

### 动作与反应

- **标准型**：动作 → 反应。用于清晰交代直接因果。
- **反应前置型**：反应 → 揭示动作。用于让观众先看到结果，再理解原因。
- **动作并置型**：多个动作 → 总反应。用于压缩时间、展示规模或累积压力。
- **反应省略型**：动作 → 不展示反应。用于有依据的留白，不得用来逃避必要信息。
- **动作隐藏型**：声音中的动作 → 画面中的反应。用于声画分离和想象空间。
- **反应延迟型**：动作 → 日常延续 → 迟到的反应。用于表现冲击后的消化过程。
- **同步型**：动作与反应在同一镜头发生。用于保持空间关系并让观众自主选择注意点。
- **反应链型**：一个动作引发多个连续反应。用于群戏和事件扩散。
- **链式衔接型**：上一组的反应同时成为下一组的动作。用于连续推进。

只选最符合当前组信息关系的一种主结构；需要组合时说明主次和切换点。

### 切镜与连接

- **相邻景别连接**：保持视觉连续，适合常规叙事。
- **跨级景别切换**：在信息揭示、关系断裂或冲击点使用。
- **推近序列**：从空间逐步进入人物或细节。
- **拉远序列**：从人物抽离，揭示环境、后果或孤立关系。
- **匹配连接**：通过动作、构图、声音或物件连接相邻镜头。
- **硬切对比**：让内容反差本身形成判断。
- **声音桥**：让下一镜声音提前或上一镜声音延续，连接组内或组间。

先保证空间、动作和视线连续；只有叙事目的要求冲击时才主动破坏连续性。

### 对白场景

- **双人镜头或长镜头**：关系和走位比台词切分更重要时使用。
- **标准正反打**：需要稳定交代双方信息和空间关系时使用。
- **听者优先**：台词意义主要落在接收者反应上时使用。
- **说者缺席**：需要隐藏、疏离或让声音压过面孔时使用。
- **景别渐进**：权力或情绪随对话发生明确变化时使用。
- **空间介入**：环境、门窗、反射或遮挡能够承担关系信息时使用。
- **空镜承载对白**：空间比说话者更能表达后果时使用。

不要按每句台词切镜。先判断权力关系、情感暗流和信息载体，再决定序列结构。

### 标准与重点设计

大多数镜头使用简洁、清晰、符合宪法的标准设计。只有当前组位于开场、转折、高潮、结尾或视觉母题关键节点时，才考虑重点设计：

- 视觉隐喻
- 视角反转或信息揭示
- 首尾或跨场结构呼应
- 感官对比与并置
- 有依据的信息延迟或留白
- 由前文充分铺垫的视觉升华

重点设计必须回答“它改变了观众如何理解当前叙事什么”。“更好看”“更有电影感”不构成理由。历史样本中的比例只说明重点设计应当稀缺，不得作为当前项目配额。
