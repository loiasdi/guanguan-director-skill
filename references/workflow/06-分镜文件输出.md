# 第六步：分镜文件输出

## 节点契约

- 节点：`N6`
- 输入：`G5` 全部通过的 `05B-分镜表.md`
- 循环单元：表格行、时间码或格式校验项
- 输出：验证通过的 `.xlsx`；工具不足时输出明确标识的 `.csv` 并保留 Markdown
- 出边：`G6 修正 → N6 当前错误项`；`G6 降级 → CSV/Markdown`；`G6 通过 → 完成`

N6 是确定性转换节点，不重新设计镜头、不润色文本、不改变 N5 已确认的内容。

## 执行顺序

1. 读取 `05B-分镜表.md`。
2. 检查九列、镜号、时间码、必填内容、镜头数量和总时长。
2A. 对 Markdown O7 执行 `scripts/validate_storyboard_output.py`，确认每行画面内容包含规定的视觉阶段标签；失败时回退 N5.4，不能在 N6 直接补写。
3. 将确认版转换为结构化表格。
4. 应用列宽、换行、边框、表头和对齐样式。
5. 重新读取生成文件，核对行数、文本和时间码与 Markdown 版一致。
6. 通过 G6 后交付；工具失败时执行降级输出，不伪称已生成 xlsx。

## 输出前校验

- 九列顺序必须是：镜号、时长、摄影角度、景别、画面内容、场景、声音、备注、叙事目的。
- 镜号必须从 1 开始连续；多行对白不得重复伪造镜号。
- 时间码必须使用数值起止时间，并与前一镜连续；最后一镜也必须有数值结束时间。
- 画面内容、场景和声音不能因转换而丢失；空备注允许为空。
- 总时长和镜头数量必须与 Markdown 版一致。
- 不能存在“待补”“稍后填写”等未完成占位符。

发现数据错误时，区分两类：

- 转换错误：N6 在当前循环内修正。
- N5 源数据错误：回退到受影响的镜头/批次，按 00C 重新执行 G5 后再进入 N6。

## xlsx 规范

- 文件名：`06-[项目名称]分镜表.xlsx`
- 单 Sheet；Sheet 名优先使用项目名称。
- Sheet 名超过 Excel 限制或含非法字符时，生成可读的安全名称，并在交付说明中注明。
- 表头加粗，使用浅灰底色。
- 所有单元格自动换行，行高适配内容，使用细线全框。
- 镜号列居中，其余列左对齐。
- 字体使用标准中文字体，10-11pt。

| 列 | 建议宽度 |
|---|---|
| 镜号 | 6 |
| 时长 | 14 |
| 摄影角度 | 12 |
| 景别 | 10 |
| 画面内容 | 50 |
| 场景 | 14 |
| 声音 | 40 |
| 备注 | 25 |
| 叙事目的 | 50 |

## 验证循环

```text
生成文件
  → 重新打开
  → 比较列名和有效行数
  → 抽查首镜、末镜和每个场景边界
  → 检查时间码连续与总时长
  → 发现转换错误则修正并重新生成
  → 最多三轮后执行降级
```

验证通过条件：文件可打开、九列完整、内容与 `05B-分镜表.md` 一致、时间码连续。

## 降级输出

无法生成或验证 xlsx 时：

1. 输出 `06-[项目名称]分镜表.csv`。
2. 保留 `05B-分镜表.md` 作为完整可读版本。
3. 在 `00-state.yaml` 或对话检查点中记录失败原因和未完成校验。
4. 不得声称 xlsx 已生成。

CSV 必须使用 UTF-8 编码、固定九列顺序；字段内的逗号、双引号和换行按 CSV 转义规则处理，空备注保留为空值，多行对白不得重复镜号。生成后至少核对表头、有效行数、首末镜和时间码与 O7 一致。
