# 第五步 C：九列分镜数据规范

## 规则契约

- 使用节点：`N5.4`
- 输入：当前批已通过内部检查的镜头组序列、上一批末镜和累计时间码
- 输出：符合九列 schema 的 Markdown 分镜数据
- 用途：约束字段、粒度、时长和 Markdown 预览
- 不负责：创意镜头设计、闸门、批次合并和文件导出

## 目录

- 九列标准格式
- 各列填写规范
- 粒度控制
- Markdown 预览格式

> 本文件不决定导演风格；所有摄影、节奏、声音和意象选择必须来自已确认的全片视听宪法与第三步节奏规划。

> 本文件不估算镜头时长。每镜 `duration_seconds` 必须已经由 05B 在镜头内容完成后算出；05C 只生成累计时间码并校验连续性。

## 一、九列标准格式

基于用户实际导演作品的分镜表，统一为以下九列结构：

| 列名 | 说明 | 示例 |
|------|------|------|
| **镜号** | 从1开始的连续编号 | 1, 2, 3... |
| **时长** | 时间码格式，标注起止时间 | 00:00-00:03 |
| **摄影角度** | 俯仰维度的摄影机角度 | 平视、俯拍、仰拍、微俯拍、极高俯拍 |
| **景别** | 画面中人物的呈现比例 | 大全景、全景、中景、中近景、近景、特写 |
| **画面内容** | 该镜头中可见的视觉内容 | 角色动作、环境描述、视觉效果 |
| **场景** | 拍摄场景/空间 | 城市街道、室内客厅、抽象空间 |
| **声音** | 该镜头中的所有声音元素 | 对白、旁白、音效、配乐 |
| **备注** | 特效、字幕、镜头运动等技术说明 | 慢动作、字幕出现、焦点转换 |
| **叙事目的** | 该镜头在全片叙事中的功能和视听意图 | 见叙事目的写作规范 |

## 二、各列填写规范

### 镜号

- 连续整数编号，从1开始
- 按 `scene_order → group_order → local_shot_id` 的顺序，把 05B 的组内临时编号映射为全局连续镜号
- 在批次检查点保留 `local_shot_id → 镜号` 映射，九列公开表只显示全局镜号
- 如果一个镜头中有多句对白需要分行展示，只在第一行填写镜号，后续行留空
- 最后一镜仍使用正常镜号；在备注中标注“全片结束”

### 时长

- 格式：`MM:SS-MM:SS`；长内容可使用 `HH:MM:SS-HH:MM:SS`
- 起始时间为上一镜的结束时间
- 所有镜头都必须填写数值起止时间，包括最后一镜，以便计算单镜和全片时长

#### 时间码转换与校验

1. 只读取声明 `timing_schema: shot-timing-v2` 的 05B 序列；含旧预算字段或缺少必要计时字段时立即退回 N5.3。
2. 按 `scene_order → group_order → local_shot_id` 读取 05B 已确认的 `duration_seconds`。
3. 第一镜从零开始；后一镜起点严格等于前一镜终点。
4. 不得在格式化时根据景别、镜头类型、平均镜长、旧 O4/O6 区间或目标片长修改 `duration_seconds`。
5. 缺少可复算 `duration_basis`、对白计数/语速/停顿数据、静态空镜 `exit_condition`，或超过 10/15 秒却未通过 05B 对应检查时，退回 N5.3，不得在 05C 补一个数字。
6. 批次总时长等于本批各镜 `duration_seconds` 之和；场景和全片总时长由批次继续自下而上汇总。
7. 若自然总时长与项目硬约束冲突，登记差值并回退相应创作节点；不得均摊、拉伸或压缩时间码来贴合目标。

### 摄影角度

标准用词（只使用以下术语）：
- **平视** / **平拍**：摄影机与被摄物体平齐
- **俯拍**：从上方向下拍摄
- **微俯拍**：轻微的俯拍角度
- **仰拍**：从下方向上拍摄
- **极高俯拍**：鸟瞰/上帝视角
- **低机位**：摄影机贴近地面

当镜号为纯文字/字幕画面时，填写"平视"或 `-`

### 景别

标准用词（按由远到近排列）：
- **大全景/远景**：人物极小，环境占绝大部分
- **全景**：人物全身可见，环境完整
- **中远景**：人物膝盖以上
- **中景**：人物腰部以上
- **中近景**：人物胸部以上
- **近景**：人物肩部以上
- **特写**：人物面部或物件局部
- **大特写/微距**：极端局部（眼睛、嘴唇、文字）

可标注景别变化：`特写转全景`、`近景转中景` 等

当镜号为纯文字/黑屏时，填写 `-` 或 `纯黑`

### 画面内容

**这是分镜表最核心的列。** 必须包含摄影机能拍到的所有关键视觉信息：
- 角色的物理动作（不写心理活动）
- 环境的关键视觉元素
- 画面中出现的文字/字幕内容
- 视觉特效的描述

画面内容必须由 05B 的 visual_timeline 按 phase_id 顺序确定性转译，并覆盖 visual_coverage 列出的全部阶段，不得只复制 visible_action 摘要。公开九列表格中，画面内容必须使用以下结构化句式，不能只写一句无阶段标记的摘要：

进入：镜头开始时观众看到的状态；过程：动作/台词期间发生的可见变化；变化/反应：人物、物件、光线、焦点或空间关系的变化；退出：切镜前形成的结果或下一镜入口。

如果同一镜头内有多段对白，必须把台词之间发生的动作、反应、光线、焦点、构图或物件变化写入同一行；不能因为没有剪切就删除中间阶段。画面内容可以是一个连续动作句段，不要求增加剪辑。

写法要求：
- 用动作句，不用状态句（"老王推开门"而非"老王站在门口"）
- 只写看得见的，不写想得到的
- 关键道具/物件需明确提及
- 如有画面中的文字（字幕、标题），原文写入
- 按 visual_timeline 的发生顺序连接句子，使用“随后”“同时”“此时”等关系词
- 不得把 viewer_reads、叙事目的或心理判断当成画面内容
- visual_coverage 中列出的 phase_id 必须逐项出现在画面内容中；缺少任何一个阶段，退回 N5.3
- 所有正常镜头必须包含“进入：”和“退出：”；有动作或对白的镜头必须包含“过程：”；时长达到 8 秒的镜头必须包含“变化/反应：”
- 静态空镜可将“过程：”写为“过程：画面保持，观众读取……”，但必须有明确读取对象和退出条件

### 场景

- 写明空间类型和具体位置
- 如果同一镜头内空间变化，标注变化
- 抽象/非现实空间标注为"抽象空间"或"纯黑/纯白背景"
- 片尾字幕标注为"纯色背景"或"黑屏"

### 声音

分类填写，一个镜头中可能同时包含多种声音元素：
- **对白**：`角色名："台词内容"` 或 `角色名台词`
- **旁白/画外音**：`旁白："台词内容"` 或 `角色名画外音："内容"`
- **配乐**：描述音乐的风格和功能（"轻快的复古爵士乐起"、"音乐渐强"）
- **音效**：具体的声音描述（"雨声"、"脚步声"、"金属撞击声"）
- **静默**：当刻意无声时标注"无声"或"静默"

### 备注

技术性补充信息。**不需要每个镜头都填写**——只在有特殊技术要求时标注：
- **镜头运动**：推镜头、拉镜头、横移、摇移、斯坦尼康跟拍
- **特效**：CG特效、实拍特效、滤镜
- **字幕**：字幕出现的位置和样式
- **焦点**：焦点转换（Focus pull）
- **速度**：慢动作、加速、定格
- **色彩/滤镜**：复古噪点、去饱和、特定色调
- **构图说明**：对称构图、纵深构图、分屏等

常规的平视固定机位镜头不需要写备注——留空即可。只有当这个镜头的拍摄方式偏离"默认"时才标注。

### 叙事目的

叙事目的来自第一步的场景功能分析，并在第五步转译为“结构功能 + 具体视听手段”的一句话。

写法要求：
- 一句话覆盖结构功能和导演意图
- 具体到视听手段
- 不使用"角色意识到"等心理描写
- 语气客观分析

## 三、分镜表的粒度控制

### 一个镜头一行

每一个cut（剪辑点）对应一行。判断标准：如果摄影机剪辑了（即画面发生了不连续的跳转），就是一个新镜号。

以下情况**不算**新镜号（仍在同一行内）：
- 镜头内的推拉摇移（摄影机运动但未剪辑）
- 焦点转换
- 同一镜头内角色的进出画

以下情况**算**新镜号：
- 硬切到新画面
- 叠化/淡入淡出后的新画面
- 跳切（同一角度但时间跳跃）

### 多句对白的处理

当一个镜头内有多句对白，有两种处理方式：

**方式一（推荐）：** 对白全部写入"声音"列，画面动作的变化写入"画面内容"列。一个镜头一行。

**方式二：** 如果一个镜头内的对白涉及多个角色的多轮对话，可以拆成多行——第一行写镜号和完整画面信息，后续行只填"声音"列，其余列留空。

### 粒度与时长不得互相反推

镜头数量由必要切点决定，镜头时长由 05B 的实际声音和画面时间线决定。不得先按成片时长推算镜头数量，也不得用镜头数量反推平均镜长。

### 画面覆盖检查

每个镜头进入 G5 前必须完成以下检查：

- 05B 存在 visual_timeline，且所有阶段均有 source。
- 05B 存在 visual_coverage，且每个 phase_id 都能在 visual_timeline 中找到。
- 时长达到 8 秒时，visual_timeline 至少有 2 个阶段且至少有 2 种 change_type；达到 12 秒时，至少有 2 个阶段且存在可观察的过程、反应、焦点、空间关系或动作结果变化。
- 九列“画面内容”逐项覆盖 visual_timeline 的关键可见阶段；遗漏任何剧本明确动作、物件变化、光线变化或退出结果都退回 N5.3。
- 九列“画面内容”符合“进入/过程/变化或反应/退出”结构；只写一句摘要的镜头退回 N5.4 重写。
- 对白、声音桥或声音事件不能替代画面阶段；可听内容必须仍保留在“声音”列。

## 四、Markdown预览格式

在进入 N6 前，分镜表以 Markdown 表格形式预览；`human` 批次等待确认，`auto/sample` 批次按 00C 继续：

```markdown
| 镜号 | 时长 | 摄影角度 | 景别 | 画面内容 | 场景 | 声音 | 备注 | 叙事目的 |
|------|------|---------|------|---------|------|------|------|---------|
| 1 | 00:00-00:03 | 平视 | 全景 | 纽约街道，行人穿行... | 城市街道 | 旁白："..." / 环境音 | 特效：发光蓝线 | 交代空间背景与核心视觉设定。 |
| 2 | 00:03-00:05 | 俯拍 | 特写 | 角色的脚步踏过蓝线... | 街道地面 | 脚步声 | 低机位 | 展示人物与设定的空间关系。 |
```

由于Markdown表格在列内容过长时可读性较差，可以改用以下分块格式：

```
───────────────────────────
镜 1 | 00:00-00:03 | 平视 | 全景
画面：纽约街道，行人在斑马线上穿行。一条发光的蓝线横向贯穿画面。
场景：城市街道
声音：旁白："2月8号，一条线出现在了城市里。" / 环境音 / 轻快配乐
备注：特效——发光蓝线；字幕
目的：交代故事发生的空间背景与核心视觉设定（蓝线及其初始高度）。
───────────────────────────
镜 2 | 00:03-00:05 | 俯拍 | 特写
画面：一只流浪狗在雨后的街道上向前走，蓝线穿过它的腿部下方。
场景：城市街道
声音：旁白："根本没人会在意低海拔的世界。"
备注：特效——蓝线与实体交互
目的：说明初始高度极低，尚未对人类生活产生明显影响。
───────────────────────────
```

将本批九列数据交回 `05-分镜拆解流程.md`。本文件不决定批次何时通过、合并或进入 N6。
