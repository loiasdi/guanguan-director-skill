# 第四步：剧本视听化微调

## 节点契约

- 节点：`N4`
- 输入：原剧本、通过的全片视听宪法与节奏规划
- 循环单元：单个候选修改处
- 输出：包含全部场景、行动、对白、旁白、画外音、字幕和声音的完整可拍执行稿，并附“原文/微调/理由”修改记录
- 出边：`G4 通过 → N5`；`G4 修改 → N4 当前修改处`

## 边界

微调是导演执行层的修正，不是重写故事。不得改变核心戏剧动作、人物弧光方向、主要角色和已确认的全片视听宪法。

## 先做视听化修正

将“角色觉得、意识到、感受到、气氛变得紧张”等不可拍判断，改成可见的动作、空间变化、物件变化或可听的声音。不要修改正常的特效、旁白、内心独白、字幕和音效描述，它们本来就是视听语言。

## 四个焦点

1. **表演节奏**：按第三步的节奏目标拆分需要停留的动作，合并不承担重点的动作。
2. **台词对白**：默认逐字保留原剧本对白、旁白和画外音。只有用户明确确认内容改写时，才允许调整文字；导演执行层可以增加停顿、动作和说话方式，但不能用概括、缩写或同义改写替代原文。
3. **画面内容**：增加能被拍到的细节动作和环境信息，删除不推进、不建立关系或不服务宪法的画面。
4. **意象落地**：只落实第二步已经确认的母题，安排首次出现、变化和回扣，不在微调阶段临时发明新的象征系统。

## 输出格式

O5 必须先输出完整的“可拍执行稿”，不能只输出修改清单或写“其余部分保留原文”。每个场景都必须包含未修改内容；每条对白、旁白、画外音、广播、字幕和关键声音分配稳定 `content_id`，供 N5 逐条核对。建议使用 `S场景号-D序号`、`S场景号-VO序号`、`S场景号-T序号`、`S场景号-SFX序号`。

```markdown

## 完整可拍执行稿

[完整场景正文；所有未修改原文也必须出现]

S001-D01｜角色名：完整台词原文
S001-VO01｜旁白：完整旁白原文

## 视听化修正
场景X
原文：
微调：
理由：将不可拍判断转译为可见/可听证据。

## 表演节奏
场景X
原文：
微调：
理由：与节奏规划和视听宪法的哪条规则对应。

## 台词对白
...

## 画面内容

## 意象落地
```

## 自检

- 是否只把不可拍内容转成了可拍内容？
- 每处修改是否有上游节奏或视听宪法依据？
- 台词是否保持角色口语和信息必要性？
- 新增细节是否可见、可听且可执行？
- 是否没有改变戏剧动作和人物弧光？
- 完整可拍执行稿是否逐条保留原剧本的对白、旁白、画外音、字幕、广播和关键声音？
- 所有未修改内容是否实际写入正文，而不是只用“保留原文”概括？
