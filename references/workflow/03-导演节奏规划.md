# 第三步：导演节奏规划

## 节点契约

- 节点：`N3`
- 输入：通过的剧本分析与全片视听宪法
- 循环单元：单个场景/序列
- 输出：场景级双轨节奏、相对篇幅权重、镜头组预规划与全片节奏波形
- 出边：`G3 通过 → N4`；`G3 修改 → N3 当前场景`

## 核心原则

节奏不是单纯的快慢，而是情节信息、情感重量、镜头密度和观众注意力的共同分配。先继承第一步的情节骨架，再用第二步视听宪法决定变化方式。

## 双轨节奏

逐场标注：

- **情节节奏**：松、中、紧，表示事件推进和信息交换的密度。
- **情感节奏**：轻、中、重，表示关系变化和情绪重量。

两条轨道可以错位。情节松、情感重的场景可能用少切镜头承载沉重对话；情节紧、情感轻的场景可能用快切制造荒诞或机械感。

## 导演执行层

每场戏在视听宪法约束下确定：

- 镜头密度：长镜头、标准切镜、快切或混合
- 景别重心：远景/全景、中景、近景/特写
- 相对篇幅权重：精简、标准或重点展开，并说明相对前后场景为什么更短或更长
- 转场策略：硬切、叠化、匹配剪辑、声音桥或明确的无缝连接
- 镜头组预规划：按当前剧本识别叙事单元与组内连接方式，不估算镜数和秒数

不要用“高潮一定最快”这样的硬规则。高潮可以是全片最高密度，也可以是突然降为极慢的凝视，关键是它要和前后形成可解释的差异。

## 镜头组预规划

本节点只做节奏层预规划，不冻结最终镜头组。它用于验证场景之间的相对篇幅、镜头密度和节奏波形；N5 会基于最终视听化剧本先划分戏剧节拍，再正式推导镜头组。预规划中的类型包括：

- **蒙太奇组**：并列画面压缩时间或展示规模。
- **递进组**：信息或情绪逐层增强，景别可以逐步推近。
- **因果组**：动作与反应紧密衔接。
- **对比组**：两个画面通过硬切、并置或交叉剪辑形成判断。

预规划必须写明暂定组名、叙事目的和组内连接方式。一个叙事目的如果可以由一个长镜头完整完成，不要为了填表强行拆组。N5 可依据最终剧本证据调整分组，但必须说明与本预规划的差异；改变相对节奏重心或删减重点时回退 G3。

## 时长职责边界

N3 不输出场景、镜头组或单镜的具体秒数，也不使用平均镜长反推场景长度。此时尚未确定完整台词承载、镜内动作、并发关系和切点，具体时长不可计算。

若用户给出目标片长，将其登记为项目级硬约束或期望值，并标出压缩优先级与不可压缩内容；不要向各场景预分秒数。若目标片长未知，只输出相对篇幅关系，不生成总时长区间。实际时长由 N5 在完整镜头设计后自下而上计算，再与目标片长比较。

## 输出格式

```markdown
# 导演节奏规划｜项目名

## 全片节奏逻辑
[情节与情感的总体波形，说明高点、低点、呼吸点]

## 场景规划
### 场景X｜地点 / 时间
- 叙事任务：
- 情节节奏：松 / 中 / 紧
- 情感节奏：轻 / 中 / 重
- 镜头密度与景别重心：
- 相对篇幅权重：精简 / 标准 / 重点展开
- 转场策略：
- 镜头组预规划：
  - 暂定组A｜类型｜叙事目的｜连接方式
- 节奏理由：

## 节奏诊断
[问题、证据、调整建议]
```

## 自检

- 每场是否有双轨节奏？
- 镜头策略是否从视听宪法推导？
- 预规划镜头组是否共享一个叙事目的，并为 N5 留有依据剧本节拍调整的空间？
- 全片是否有起伏、铺垫和呼吸？
- 最长场景内部是否有变化？
- 是否避免在镜头内容生成前伪造场景、镜头组或单镜秒数？
- 若存在目标片长，是否只登记约束、压缩优先级和不可压缩内容？
