# 关关导演｜输入边界与交接协议

## 适用范围

本 Skill 只处理“待拍的影视剧本或可拍场景文本”在导演策划层的工作：剧本导演分析、统一视听宪法、节奏规划、视听化微调、镜头组/分镜拆解和分镜表导出。

以下请求不直接触发完整六步流程：

| 请求 | 处理方式 |
|---|---|
| 小说、散文或文学文本的视觉想象 | 先确认是否要改编为待拍影视文本；否则只做一般性视觉分析 |
| 单独镜头或视频生成提示词 | 转交提示词/视频生成 Skill；本 Skill 只在用户要求纳入已确认分镜时处理 |
| 故事板图片、线稿分镜图 | 转交故事板 Skill；本 Skill 可提供已确认的镜头数据 |
| 已拍视频、素材剪辑、剪辑工程 | 转交剪辑或素材分析流程；不得当作待拍剧本继续拆镜 |
| 纯美术、服化道或摄影器材方案 | 仅在已有视听宪法后作为下游专项，不启动 N1-N6 |

## 输入模式

判定输入模式后，必须先按 [00D-输入归档与版本协议.md](00D-输入归档与版本协议.md) 完成原文归档和 manifest，再进入 N1。已有项目恢复时先验证 manifest 指向的剧本版本存在；丢失时不得用 O1-O5 摘要反推原剧本。

开始 N1 前必须登记一个 `input_mode`：

- `script`: 有完整剧本或可拍场景文本。
- `synopsis`: 只有梗概/故事构想。先建立带 `provisional` 标记的最小场景骨架；缺失的行动、对白、时空和结局不得擅自补写，因此最多推进到导演命题候选，除非用户确认补充或接受假设。
- `scene`: 单场戏或局部场景。输出只对该场景有效，不生成“全片”宪法；全片规则字段改为“本场暂定规则”。
- `handoff`: 接收编剧 Skill 的导演交接包，按下节字段归一化后进入对应恢复节点。
- `artifact_resume`: 已有本 Skill 产物或检查点，先按 00A 检查 `shot-timing-v2`，再从版本索引确定最早有效节点恢复。

没有明确 `input_mode` 时，先根据实际材料判断；不能把梗概伪装成完整剧本。

## 编剧交接包

支持接收以下字段，不覆盖导演决策：

| 字段 | 导演用途 |
|---|---|
| `project_constraints` | 格式、目标时长、集/季范围、制作与内容限制 |
| `character_bible` | 角色稳定 ID、关系和不可违背事实 |
| `structure` | 结构节点、节拍和已确认的叙事功能 |
| `scene_list` | 稳定场景 ID、地点/时间、人物、目标、结果；上游估算时长只作来源记录，不作为 N5 预算 |
| `script` | 当前剧本版本和场景原文 |
| `continuity_state` | 状态、道具、公开信息、伏笔及相邻场锚点 |
| `unresolved_issues` | 未决问题、暂定假设、降级项和用户决定 |

`provisional` 内容只能作为约束或假设，不能当作已确认事实。所有场景引用沿用交接包的稳定 ID；缺失 ID 时先生成并登记映射表。

## 局部与恢复入口

用户只要求某个产物或局部修改时，按以下入口处理：

- 只有 O1：从 N2 开始，不重做 N1。
- 只有 O3：从 N3 开始，并核验 O1 版本。
- 只有 O6：从 N5.3 开始，要求 O6 已通过 G5A。
- 只有部分 O7：先验证其上游序列符合 `shot-timing-v2`；不符合时从最早受影响镜头组的 N5.3 恢复，而不是直接修改批次。
- 已有 O6/O7/O8 且用户要讨论拍法：进入 N5R；先比较方案，确认后再按影响层级回退。
- 只改格式：直接进入 N6，不改镜头内容。
- 只有检查点：以 `00-state.yaml` 的 `resume_action` 和版本索引为准，不重新初始化游标。

## 规模定义

| 格式 | 定义 | 默认运行范围 |
|---|---|---|
| 短片 | `<=15:00` | 单部 |
| 中片 | `>15:00` 且 `<60:00` | 单部，按场景批次 |
| 长片 | `>=60:00` | 单部；超过 150 分钟按章节/场景分文件 |
| 剧集 | 有集数边界的连续项目 | 默认一次处理一集；整季必须逐集建立状态 |

目标时长未知时，N3 不得生成全片、场景或镜头组时长区间。目标时长已知时，也只登记为项目级硬约束或期望值，不向场景和镜头组预分秒数。N5 必须在镜头内容完成后自下而上计算自然时长，再比较目标；冲突通过内容或结构调整解决，不得拉伸、压缩或均摊镜头时间。

## 媒体与读取能力

- PDF/DOCX 只有在宿主成功提取文本后才能作为 `script`；扫描件需要 OCR。
- 图片只能作为视觉参考，不能声称已读取其中完整剧本。
- 音频/视频必须先有可核验转录或镜头日志，才能用于声音或节奏判断。
- 未读取、无法解析或来源不明的内容统一标记为“未知/待确认”。
