# 关关导演 Skill

`guanguan-director` 是一个面向影视剧本的导演分析与分镜设计 Skill。

它从剧本分析出发，建立统一的导演命题和视听规则，再完成节奏规划、视听化微调、镜头组拆解、逐组分镜设计以及九列表格输出。

## 适用范围

- 影视剧本和可拍场景文本的导演分析
- 统一导演风格与视听宪法设计
- 镜头组和分镜拆解
- 已有分镜的局部讨论与优化

## 目录

- `SKILL.md`：Skill 主入口
- `references/workflow/`：声明式流程与各阶段规则
- `references/style-library/`：导演风格参考资料
- `scripts/`：分镜内容与时长校验脚本

镜头组序列必须按 `group_id` 独立保存并通过校验后，才能汇总最终分镜表。
